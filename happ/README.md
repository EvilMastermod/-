# Happ VPN — US/RU + backups

This branch contains an experimental one-link subscription builder for Happ.
The servers are **public third-party proxies**, not owned or tested by the project.

Importer: https://raw.githubusercontent.com/EvilMastermod/-/happ-vpn/happ/subscription.txt
Node source: https://github.com/rtwo2/FastNodes

Select **Xray TUN** in Happ. In Settings → Subscriptions, enable **Ping on Launch**.

Important: country tags and uptime are not guaranteed. Do not send sensitive information over an untrusted public proxy.
