# AutoHarvester — Fabric 1.21.11

Клиентский мод. Нужны Minecraft Java 1.21.11, Java 21, Fabric Loader и Fabric API для 1.21.11.

- Ё (клавиша под Esc): включить / выключить. Цветные сообщения в чате.
- Навести прицел на сундук, нажать =: выбрать место выгрузки.
- При включении запоминается центр рабочей области, радиус — 12 блоков.
- Зрелые пшеница, морковь, картофель, свёкла и адский нарост собираются и пересаживаются из инвентаря.
- Собираются ягоды, тыквы, арбузы и верхние блоки тростника/бамбука.
- Деревья распознаются по стволу на земле с естественной листвой. Рубятся доступные блоки. После рубки высаживается саженец из инвентаря.
- Дубовая листва разрушается для выпадения яблок. Яблоки выпадают с обычной вероятностью Minecraft; гарантированного яблока с каждого дерева нет.
- Костная мука из инвентаря применяется только к саженцам деревьев.
- При наличии мотыги автоматически вспахивает свободные землю, дёрн, тропинки и каменистую землю в рабочей области.
- Маршрут сохраняется, повороты ограничены по скорости, цель подбора фиксируется до подхода.
- Выпавшие предметы подбираются при подходе.
- Полный инвентарь вызывает поход к выбранному сундуку. Инструменты, экипировка, семена, саженцы, костная мука и один запас посадочных овощей сохраняются.
- При заполненном сундуке или недоступном пути мод останавливается с сообщением.

Для первого запуска используй ровную открытую ферму, обычные небольшие деревья и сундук рядом. Мод не летает, не строит столбы для доступа к высоким кронам и не телепортирует предметы. Высокие недоступные блоки пропускаются. Для тёмного дуба нужны четыре саженца 2×2; мод запоминает основания срубленных стволов. Какао собирается, но автоматически не пересаживается. Выбор сундука сбрасывается при смене мира. На серверах действия зависят от прав игрока и правил сервера.

Сборка: GitHub Actions → Build AutoHarvester → artifact AutoHarvester-1.21.11. Готовый мод внутри архива артефакта имеет расширение .jar. Исходники нельзя переименовывать в .jar.
