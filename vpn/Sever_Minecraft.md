# Север — Minecraft для Happ

[Подписка с названием, описанием и рабочим узлом](https://raw.githubusercontent.com/EvilMastermod/-/main/vpn/Sever_Happ.txt)

Если эта ссылка уже добавлена в Happ, нажми обновление подписки. Вместо служебной строки она теперь содержит реальный VLESS-узел. Название: «❄ Север VPN • Minecraft». Собственного лимита трафика у подборки нет; лимиты и доступность публичного узла зависят от владельца. Счётчики фактического расхода трафика не ведутся.

[Основной JSON с автопрофилями](https://raw.githubusercontent.com/EvilMastermod/-/main/vpn/Sever_Minecraft.json)

Старую JSON-подписку можно обновлять по прежнему адресу. В ней сохранены профили SkyTime, Space, FunSky, «Авто — Россия», «Питер — Авто RU» и общего резерва. Сейчас все они используют один рабочий российский узел: полноценного выбора между разными выходами и рабочего запасного узла пока нет. Профиль «Россия — основной» закрепляет тот же узел вручную.

Текстовая подписка с описанием содержит фиксированный узел; автопрофили доступны в JSON. Она больше не пытается автоматически менять URL: эта функция требует зарегистрированного Provider ID в Happ и без него не сработала. Прежняя инструкция «обновить ещё раз для загрузки JSON» была неверной.

## Проверка 25.10.2026 (UTC+5)

Шесть прежних узлов не ответили в текущей проверке и исключены. Оставшийся выход подтвердил RU через HTTPS с проверкой сертификата. Два запроса Minecraft Java status/ping на каждый адрес дали ответы:

| Адрес | Успешные проверки | Медиана пинга |
|---|---:|---:|
| mc.skytime.su | 2/2 | 87 мс |
| mc.space-times.fun | 2/2 | 190 мс |
| mc.funsky.ru | 2/2 | 107 мс |

Замеры сделаны на одном компьютере Windows, не на проблемном компьютере в Санкт-Петербурге. Они подтверждают ответ сервера, но не устранение таймаута при входе в игру из Петербурга. Город размещения VPN-узла не подтверждён. Полный вход в мир в этой проверке не выполнялся.

Проверка доступности в автопрофилях выполняется через HTTPS каждые 60 секунд; она не измеряет пинг Minecraft постоянно. При появлении нескольких узлов переключение может потребовать повторного подключения к игре. Не подтверждённые рабочие узлы США не добавлялись.

Метаданные передаются согласно [документации Happ](https://github.com/HappDev/happ_su/blob/main/dev-docs/app-management.md). Установленный Happ 4.3.0 не принимает строки метаданных перед массивом JSON, поэтому описание и автопрофили пока предоставляются в разных форматах. Формат JSON и каждый профиль проверены установленным Xray.
