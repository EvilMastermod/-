# Север — Minecraft для Happ

[Подписка с названием, описанием и серверами](https://raw.githubusercontent.com/EvilMastermod/-/main/vpn/Sever_Happ.txt)

Если ссылка уже добавлена в Happ, нажми обновление. Вместо служебной строки она теперь содержит реальные узлы. Название: «❄ Север VPN • Minecraft». Подборка не вводит собственного лимита трафика; доступность и ограничения публичных узлов зависят от владельцев. Счётчики фактического расхода трафика не ведутся.

[Основной JSON с автопрофилями](https://raw.githubusercontent.com/EvilMastermod/-/main/vpn/Sever_Minecraft.json)

Старую JSON-подписку обновляй по прежнему адресу. В ней 8 профилей на 2 разных узлах: Россия — 1, США — 1. Автопрофили повторно используют эти узлы, это не отдельные серверы. Для каждой игры выбираются только узлы с двумя успешными игровыми ответами. Американский узел, не ответивший Space, не включается в пул Space.

«Питер — Авто RU» использует проверенные российские выходы; расположение узлов в Санкт-Петербурге не подтверждено. Сейчас российских узлов 1; при одном узле выбирать внутри российского пула не из чего. HTTPS-проверка выполняется каждые 60 секунд и не измеряет игровой пинг постоянно. При смене выхода игровая сессия может потребовать переподключения.

Текстовая подписка с описанием содержит узлы для ручного выбора; автопрофили находятся в JSON. Автоматическая смена URL убрана: для неё [документация Happ](https://github.com/HappDev/happ_su/blob/main/dev-docs/app-management.md) требует зарегистрированный Provider ID. Прежняя инструкция «обновить ещё раз для загрузки JSON» была неверной. Happ 4.3.0 на этом компьютере не принял строки метаданных перед JSON, поэтому шапка и автопрофили пока доступны в разных форматах.

## Проверка 25.10.2026 (UTC+5)

Шесть прежних узлов не ответили и исключены. Новые кандидаты взяты из публичных подборок [vpn-free-russia](https://github.com/aviamastersgh/vpn-free-russia), [Config-Finder](https://github.com/Mokafela/Config-Finder), [Automate-V2ray-Config-Collector](https://github.com/Idolvpn/Automate-V2ray-Config-Collector) и [FastNodes](https://github.com/rtwo2/FastNodes). Страна выхода проверена отдельно через HTTPS, независимо от подписи в источнике. В таблице — медиана двух ответов Minecraft Java status/ping.

| Узел | mc.skytime.su | mc.space-times.fun | mc.funsky.ru |
|---|---:|---:|---:|
| Север • Россия 01 | 87 мс (2/2) | 190 мс (2/2) | 107 мс (2/2) |
| Север • США 01 | 109 мс (2/2) | не подтверждён | 91 мс (2/2) |

Замеры выполнены на одном компьютере Windows, не на проблемном компьютере в Петербурге. Они подтверждают ответы игровых серверов, но не устранение таймаута при полном входе в мир на другом компьютере. Каждый JSON-профиль проверен установленным Xray, текстовые ссылки проверены обратным преобразованием без потери параметров подключения. Проверка импорта обновлённой текстовой подписки в интерфейсе Happ пока не выполнена из-за сбоя инструмента управления окнами.
