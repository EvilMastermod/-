# Север — Minecraft для Happ

Бесплатная подборка публичных VPN-узлов для SkyTime, Space и FunSky. 7 разных выходных IP: Россия — 5, Швеция — 2. Всего 12 профилей; автопрофили используют те же узлы, это не дополнительные серверы.

[Ссылка подписки для Happ](https://raw.githubusercontent.com/EvilMastermod/-/main/vpn/Sever_Minecraft.json)

Если подписка уже добавлена, обнови её в Happ. Повторно добавлять ссылку не нужно.

## Как выбрать

- **Авто — Россия**: начни с него, если нужен российский выход.
- **SkyTime / Space / FunSky — Авто**: для каждой игры отобраны до трёх узлов по повторным игровым замерам. Сначала учитывается отсутствие сбоев, затем задержка. Если этот профиль недоступен, попробуй общий резерв.
- **Авто — Minecraft + резерв**: все прошедшие проверку страны. Для каждого из трёх игровых адресов используются только узлы, подтвердившие ответ именно этой игры.
- **Профили стран**: фиксированный узел для ручного выбора. Под названием указаны игры, диапазон измеренной задержки и дата проверки. Sky = SkyTime, Space = Space, Fun = FunSky; «3 игры» означает все три.

Автовыбор проверяет HTTPS-задержку каждые 60 секунд. Это не непрерывное измерение пинга Minecraft. При смене IP текущая игровая сессия может оборваться — тогда переподключись к серверу. Весь трафик идёт через выбранный профиль, поэтому для одной игры можно выбрать её отдельный автопрофиль.

Задержка зависит от провайдера и нагрузки. Это снимок проверки, а не обещание постоянной доступности. Вход в игровой аккаунт, UDP/Bedrock и обход анти-VPN или блокировки аккаунта не проверялись. У публичных узлов могут меняться доступность и страна выхода. Подборка не является отдельной VPN-инфраструктурой; автоматической замены умерших узлов на GitHub пока нет.

Короткие подписи соответствуют [формату Happ](https://www.happ.su/main/dev-docs/app-management#server-description-in-the-subscription): до 30 символов в `meta.serverDescription`. Формат JSON и все профили проверены установленным Xray.
