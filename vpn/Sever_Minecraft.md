# Север — Minecraft для Happ

[Единая подписка со всеми профилями](https://raw.githubusercontent.com/EvilMastermod/-/main/vpn/Sever_Happ.txt)

Если ссылка уже добавлена в Happ, нажми обновление. По адресу Sever_Happ.txt теперь находится полный JSON со всеми восемью профилями, включая Space, SkyTime, FunSky, Петербург и общий автовыбор. Это прежняя ссылка — добавлять ещё одну подписку не нужно. Подборка не вводит собственного лимита трафика; доступность и ограничения публичных узлов зависят от владельцев.

[Основной JSON с автопрофилями](https://raw.githubusercontent.com/EvilMastermod/-/main/vpn/Sever_Minecraft.json)

Старую JSON-подписку обновляй по прежнему адресу. В ней 8 профилей на 2 разных узлах: Россия — 1, США — 1. Автопрофили повторно используют эти узлы, это не отдельные серверы. Для каждой игры выбираются только узлы с двумя успешными игровыми ответами. Американский узел, не ответивший Space, не включается в пул Space.

«Питер — Авто RU» использует проверенные российские выходы; расположение узлов в Санкт-Петербурге не подтверждено. Сейчас российских узлов 1; при одном узле выбирать внутри российского пула не из чего. HTTPS-проверка выполняется каждые 60 секунд и не измеряет игровой пинг постоянно. При смене выхода игровая сессия может потребовать переподключения.

Обе ссылки теперь содержат один и тот же полный JSON. Заголовок и объявление ранее передавались текстовой версией подписки; сохранит ли их установленный Happ после смены формата, пока не проверено в интерфейсе. При новом добавлении ссылка GitHub Raw не передаёт специальные HTTP-заголовки названия и описания. Нельзя добавлять строки #profile-title перед массивом JSON: установленный Happ 4.3.0 такой файл не принял. Сохранение полной работы автовыбора имеет приоритет перед оформлением шапки.

## Проверка 25.10.2026 (UTC+5)

Шесть прежних узлов не ответили и исключены. Новые кандидаты взяты из публичных подборок [vpn-free-russia](https://github.com/aviamastersgh/vpn-free-russia), [Config-Finder](https://github.com/Mokafela/Config-Finder), [Automate-V2ray-Config-Collector](https://github.com/Idolvpn/Automate-V2ray-Config-Collector) и [FastNodes](https://github.com/rtwo2/FastNodes). Страна выхода проверена отдельно через HTTPS, независимо от подписи в источнике. В таблице — медиана двух ответов Minecraft Java status/ping.

| Узел | mc.skytime.su | mc.space-times.fun | mc.funsky.ru |
|---|---:|---:|---:|
| Север • Россия 01 | 87 мс (2/2) | 190 мс (2/2) | 107 мс (2/2) |
| Север • США 01 | 109 мс (2/2) | не подтверждён | 91 мс (2/2) |

Замеры выполнены на одном компьютере Windows, не на проблемном компьютере в Петербурге. Они подтверждают ответы игровых серверов, но не устранение таймаута при полном входе в мир на другом компьютере. Каждый JSON-профиль проверен установленным Xray; готовые автопрофили SkyTime, Space, FunSky и Петербурга получили игровые ответы. Содержимое обеих ссылок одинаково. Проверка отображения подписки после смены формата в интерфейсе Happ пока не выполнена из-за сбоя инструмента управления окнами.
