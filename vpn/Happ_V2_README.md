## Список стран

США, Россия, Германия, Нидерланды, Финляндия, Франция, Польша, Великобритания, Канада, Япония, Сингапур, Швеция, Австрия, Чехия, Швейцария, Италия, Испания, Гонконг, Южная Корея, Австралия, Тайвань, Турция и Украина.

**Доступность стран зависит от реальных проверок.** Если в стране не нашлось ни одного работающего выхода с соответствующим IP, её профиль не добавляется. Местоположение адреса входного прокси может отличаться от местоположения выходного узла.

## Россия — ускоренная проверка и отдельный автовыбор

- 🇷🇺 **РОССИЯ — БЫСТРЫЙ АВТОВЫБОР** — небольшой пул из самых быстрых ранее проверенных стабильных RU-узлов. Happ/Xray оценивает задержку локально.
- 🇷🇺 **РОССИЯ — АВТОВЫБОР — СТАБИЛЬНЫЙ** — больше запасных узлов, если быстрый режим не подключается.
- 🇷🇺 **РОССИЯ — СЕРВЕР N** — отдельные узлы без автоматического переключения, удобны для игр и Discord.
- Проверка российских адресов расширена до **360 кандидатов** и 4 специализированных источников (исходный список плюс FastNodes, CheburNet, Nosok verified).
- Отдельный GitHub Actions workflow проверяет Россию каждые 3 часа. Каждый адрес должен реально выдать российский выходной IP через Xray, а не только иметь российскую метку в названии.
- Нельзя гарантировать улучшение скорости в фиксированное число раз: сеть пользователя и загрузка публичного прокси определяют реальный результат.

## Режимы

- 🌍 **Весь мир — автовыбор**: до 180 уникальных проверенных выходов, HTTP-замеры выполняются ядром Xray во время работы на устройстве. Не гарантирует самый низкий пинг в конкретной игре.
- 🇺🇸 🇷🇺 🇩🇪 ... **Автовыбор по стране**: только работающие IP нужной страны, динамическое переключение с резервным сервером.
- 🎮 **Игры**: меньший пул серверов, предварительно отобранных по задержке.
- 🎧 **Discord RTC**: отдельные закреплённые серверы и резервные профили, чтобы голосовые соединения не перескакивали на другой VPN-узел. Для голосового UDP нужен Happ **TUN**, одной подписки недостаточно.
- **Сервер N**: ручное подключение, полезно для проверки задержки из собственной сети.

## Отбор, обновления и ограничения

Список обновляет GitHub Actions с периодичностью каждые 6 часов. Проверка использует Xray, два HTTP-запроса для оценки задержки и проверку страны выходного IP; перед публикацией генерируемые профили проверяются на ошибки конфигурации Xray.

**Пинг на GitHub ≠ твой пинг.** Из-за маршрута до твоего компьютера сервер с низкой задержкой при проверке может быть медленным у тебя. Большой пул серверов также может повысить нагрузку от проверок — поэтому есть лимит 180 узлов в одном глобальном профиле.

Публичные бесплатные прокси ненадёжны, могут внезапно исчезнуть, изменить местоположение или оказаться небезопасными. Не используй их для банков и важных аккаунтов; это не собственная частная сеть.
