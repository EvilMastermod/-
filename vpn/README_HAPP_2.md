# Happ VPN 2.0 — бесплатные публичные узлы

**Подписка Happ:**
`https://raw.githubusercontent.com/EvilMastermod/-/main/vpn/Happ_US_RU_Auto.json`

## Режимы
- **🇺🇸 США / 🇷🇺 Россия / 🇩🇪 Германия / 🇳🇱 Нидерланды / 🇫🇮 Финляндия — АВТОВЫБОР — СТАБИЛЬНЫЙ**: выбирает доступный узел по результатам периодической проверки.
- **🎮 Игровые профили**: предпочитают низкую измеренную HTTP-задержку. *Это не пинг конкретного игрового сервера.*
- **СЕРВЕР N**: ручное подключение к конкретному узлу. Используйте для сравнения задержек непосредственно в Happ.

## Обновления и проверка
- Исходники размещены в этом репозитории; бесплатные публичные узлы принадлежат третьим сторонам.
- GitHub Actions пытается обновлять и перепроверять подписку каждые 6 часов; успешный запуск можно увидеть во вкладке Actions.
- Проверяется реальная страна выходного IP через HTTPS и задержка/успех двух HTTP-запросов через Xray; для других протоколов/сетей результаты могут отличаться.
- Файл `FAST_NODES_RESULTS.json` содержит последний отчёт: число проверенных, реально ответившие узлы и их задержки с проверяющего сервера.
- Неработающие и несовместимые REALITY+WebSocket конфигурации исключаются. Все сгенерированные JSON проходят `xray run -test` до публикации.
- При временной недоступности всех новых узлов программа может сохранить прошлые в соответствующей стране; это **не гарантия** их текущей работоспособности.

## Как использовать
В Happ → «Добавить подписку» → вставьте ссылку → сохраните → обновите подписку.
Для полного туннеля используйте TUN-режим с ядром, которое поддерживает Xray/VLESS/REALITY. Если Happ показывает `n/a`, попробуйте отдельный профиль и запустите проверку задержки с устройства.
Для изменения страны выберите соответствующий профиль.

## Важные ограничения
- Стабильность/скорость/доступность сервисов не гарантируются.
- Короткие сетевые тесты не измеряют потерю UDP-пакетов или пинг в играх. Проверяйте это локально.
- Публичным узлам не следует доверять банковские операции и чувствительные учётные записи.
- Маршруты и физическая удалённость могут давать высокий пинг даже при исправном VPN.
