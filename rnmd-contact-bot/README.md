# RNMD Contact Bot v2

## Что добавлено

- `/start` → кнопка `📩 Связь`
- пользователь пишет сообщение владельцу
- при запуске владелец получает `🤖 Бот подключен`
- владелец отвечает пользователю, просто отвечая на сообщение бота в Telegram
- если ответа владельца нет 5 минут, пользователь получает:
  `⏳ Собеседник оповещён. Ожидайте ответа.`

## Важно про статус «онлайн»

Telegram Bot API не даёт боту надёжно видеть, находится ли владелец сейчас онлайн.
Поэтому автоответ срабатывает по правилу: **нет ответа владельца 5 минут**.

## Render

Нужны переменные окружения:

- `BOT_TOKEN` — токен от @BotFather
- `ADMIN_ID` — Telegram ID владельца

`PORT` и `RENDER_EXTERNAL_URL` Render задаёт автоматически.

Не публикуй BOT_TOKEN в GitHub и не отправляй его другим людям.
