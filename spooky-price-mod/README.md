# Spooky Price Collector

Клиентский Fabric-мод для Minecraft 1.21.11.

Функции:
- F6 — вручную считывает цены из уже открытого /ah и отправляет их в общую базу.
- F7 — включает/выключает пассивный сбор.
- Когда игрок сам вводит /an101…/an108, /an201…/an209 или /an301…/an309, мод запоминает текущую анку.
- В пассивном режиме при открытом аукционе отправляется только изменившееся содержимое.
- У каждого игрока свой collectorId, поэтому данные нескольких игроков объединяются в одной базе.
- Мод не проходит антибот-проверки, не кликает GUI и не выполняет серверные команды вместо игрока.

API: https://spooky-auction-bot-production.up.railway.app
Конфиг: config/spooky-price.json
